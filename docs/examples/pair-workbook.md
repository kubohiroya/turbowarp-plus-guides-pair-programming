# プラとモコのペア練習シート

「ペア練習」を開きます。Gキーを一度押して、出てくる星を数えます。次の試運転は、前の星が消えてから始めます。

| 項目 | 記入欄 |
| --- | --- |
| 最初に操作する人 | |
| 最初に確認する人 | |
| 変更前に確かめた星の数 | |
| 今回の目標 | Gキーを一度押すと星が6個出る |
| 今回変える値 | 個数を5から6にする |
| そのままにする値 | 間隔は60 |
| 変更後に確かめた星の数 | |

## 役割交代

「何を変えた」「どんな操作で確かめた」「次に何を見る」を一文ずつ伝えます。

1. 変えたこと　
2. 確かめたこと　
3. 次に調べること　

## 一つずつ試して比べる

個数6のまま、間隔が60のときと50のときを比べます。各行とも、Gキーを一度だけ押してください。
